miniledger

Live demo dashboard for account-service and transaction-service — talks directly to both over HTTP, no backend logic of its own.

account-service :4001
transaction-service :4002

System architecture

Node.js Express PostgreSQL MongoDB / Mongoose JWT Docker Compose Jest + Supertest axios-retry

account-service — key endpoints

  • POST/userscreate user + wallet (optional initialBalance)
  • DELETE/users/:userIdrefuses if balance ≠ 0
  • GET/wallets/:userIdrequires Bearer JWT
  • GET/internal/wallets/:userIdservice-to-service lookup
  • POST/internal/wallets/:id/adjustidempotent debit/credit
  • POST/auth/tokendev-only token mint

transaction-service — key endpoints

  • POST/transferorchestrates debit + credit
  • GET/transactions/:userIdpaginated history
